# Description
This project teaches you the knowledge necessary to configure a network, including TCP/IP, switches, routing, and subnet masks.
You will work through each level using a dedicated WebUI.

# Instructions
1. Download net_practice.1.8.tgz from the intranet.
2. Use `tar -xvzf` to unpack the archive data.
3. Open the included index.html, select the Evaluation tab, and choose Start!
